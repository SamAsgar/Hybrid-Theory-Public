# C08 · Leveranciers, cloud en ICT-derden

Welke externe ICT-diensten en contractuele relaties vallen binnen de afgebakende inventaris?

Onderscheid aanbieder, dienst, afnemer en afhankelijkheid. Een hardwarelijst vormt een vertrekpunt. Contractbereik en volledigheid vragen eigen bronnen.
